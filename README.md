# 大阪酒鬼地图 · Osaka After Dark

一份可以随身带走的关西酒吧地图：以鸡尾酒、威士忌和精酿为主，收录 **36 家店**，其中大阪及府内周边 24 家、京都 6 家、神户 6 家。

打开根目录的 [index.html](index.html) 即可使用，无需安装或构建。这个单独的 HTML 文件已包含店铺资料、36 张真实门头／入口参考照片，以及关西总览和 5 幅分区地图。

## 怎么打开

将 `index.html` 下载到电脑或手机，在浏览器中打开。分享或离线携带时，只需这一个文件。

支持 JavaScript 的浏览器可以按城市、酒类和关键词筛选，按评分或评价人数排序，收藏店铺、复制日文地址、拨打电话，或跳转 Google／Apple 地图。点击“地图汇总”可查看全部店铺的静态分布图，地图编号与店铺清单对应。

部分手机文件预览器不运行 JavaScript，此时仍会显示静态地图、照片，以及完整电话、地址和评分清单。交互功能需要在浏览器中打开。

| 内容 | 离线可用 |
| --- | --- |
| 店铺资料、电话、日文地址、评分快照 | 是 |
| 36 张门头／入口参考照片 | 是 |
| 6 幅静态地图及编号跳转 | 是 |
| 筛选、排序与本地收藏 | 是，需浏览器支持 JavaScript |
| 交互地图的街道底图 | 需联网 |
| 原始来源、外部导航与店铺网页 | 需联网 |

收藏保存在当前浏览器中，换浏览器或移动文件后可能不会同步。

## 资料与照片

资料查询日期为 **2026-09-18**。评分统一采用食べログ 5 分制，并附评价人数与原页链接；它们是查询时的公开页面快照，不会自动更新。电话和完整日文地址也保留了核对来源。

每家店有一张真实照片，图注明确区分门头、店铺入口、楼宇入口或招牌局部。部分照片来自较早的访店记录，例如 Cellar Infini 的入口参考照片标注为 2013 年 7 月；照片用于辨认店铺，实际装修和招牌可能变化。地下、楼上和酒店酒吧请同时查看文字地址中的楼层说明。

地图中的小圆点表示店铺坐标，编号为避免重叠会适当错开，并以连线指向对应位置。来源与第三方组件说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 从源码构建

需要 **Python 3.10 或更新版本**。在项目根目录安装依赖，再构建：

```sh
pip install -r requirements.txt
python scripts/build.py
```

如果系统中的命令是 `python3`，可使用 `python3 -m pip install -r requirements.txt` 和 `python3 scripts/build.py`。

构建会读取仓库内的店铺数据、照片、静态图册和前端文件，覆盖根目录的 `index.html`。安装好依赖后，普通构建可以离线完成，不需要重新下载照片或地图，也不需要 Node.js。

如需重新生成静态地图，例如修改了店铺坐标，执行：

```sh
python scripts/make_atlas.py
python scripts/build.py
```

`make_atlas.py` 会从日本国土地理院下载缺少的底图瓦片，将临时文件缓存到 `.cache/atlas/`，并更新 `assets/atlas.html`。首次运行或缓存不完整时需要联网；日常构建直接使用仓库中已生成的图册。

## 项目文件

```text
index.html                  可直接打开的单文件成品
requirements.txt            Python 构建依赖
scripts/
  build.py                  将数据、照片和前端资源内嵌到 HTML
  make_atlas.py             生成静态总览与分区地图
src/
  template.html             页面模板
  app.css                   页面样式
  app.js                    筛选、收藏和交互地图逻辑
data/
  cocktails*.json            鸡尾酒店铺资料
  whisky*.json               威士忌店铺资料
  beer*.json                 精酿店铺资料
  photos-*.json              照片文件、原图 URL、来源页与图注
assets/
  storefronts/              36 张店铺参考照片
  atlas.html                已内嵌底图的静态图册片段
vendor/                     Leaflet、MarkerCluster 及对应许可
THIRD_PARTY.md               第三方来源说明
```

照片清单中的 `path` 相对于项目根目录。修改照片时，同时更新相应清单中的 `sourcePage`、`imageUrl`、`caption` 和 `kind`，以保留来源。构建脚本会检查店铺编号、地址和照片对应关系；当前版本固定收录 36 家，扩充数量时也需要同步调整构建校验、图册和页面中的数量说明。

构建不会自动核实店铺信息。更新数据时，请重新核对来源，并同步修改查询日期。
